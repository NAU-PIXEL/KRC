# New conductivity in KRC -- sensitivity tests

End-to-end checks of the fitted ice conductivity once loaded into KRC:
`TI_*.png` / `Tsurf_*.tab` for high/low TI and albedo cases, layering effects
(`Effect_strat_*.png`), and relative error vs. the reference conductivity
model (`ErrorConductivity_*.png`). `Plot.py` reproduces the figures.
`Data_PlotPython/` mirrors the fit-quality data from
`Script_Fiticeproperties4KRC` for reference.
