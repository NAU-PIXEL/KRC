# Effect of solar penetration depth on best-fit thermal inertia

`EffectSolarPENvsBESTTI.py` / `Determine_highti_vssolariabs.sh` drive KRC for
absorption e-folding lengths of 1, 2 and 4 cm, with and without absorption, and
with TI/albedo perturbed by +/-20% and +/-0.1 around the best fit
(`*_bestfitti*.ascii`). Plots: `CompTIbestfit_*.png` (temperature comparison),
`Heatingrate_*cm.png` (volumetric heating rate).
