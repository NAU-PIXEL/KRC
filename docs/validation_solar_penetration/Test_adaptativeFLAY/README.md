# Adaptive FLAY test

Compares KRC runs at fixed FLAY (0.01, 0.05, 0.1) against the interface's
automatic FLAY when RADGND is active, at two thermal inertias (TI33, TI133).
`PlotComparisonSOLABS_fLAY.py` produces the comparison figures
(`TI33*.png`, `TI133*.png`) from the `Tsurf_*.tab` / `time.tab` runs.
