# Fitting ice properties for KRC

`Compute_Fit_Cond_Spec_4KRC.dvrc` fits the polynomial coefficients
(conductivity + specific heat) actually loaded into KRC via `Mat_Prop`.
`Data_PlotPython/` holds the fit data and figures (true vs. fitted
conductivity, per contact/grain-size case); `Error_2ndorderfit.png` /
`Errorrel_2ndorderfit.png` check fit order. See `README` inside.
